# Fachregeln
- Standard-Tags stammen ausschließlich aus src/tags.py.
- Zusätzlich maximal 8 freie Suchbegriffe, nicht automatisch ins kontrollierte Vokabular übernehmen.
- Keine nicht belegten Zusatzangebote aus Gewohnheit behaupten (z. B. Beichte bei jeder Messe).
- Event-URL dient als stabiler Schlüssel im Test-Sheet.
- Nur öffentlich verfügbare Eventinformationen verarbeiten. Kurze Erklärung zu den Tags speichern.
