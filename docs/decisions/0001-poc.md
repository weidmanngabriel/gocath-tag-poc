# ADR-0001: Tag-Klassifizierung
Entscheidung: öffentliche HTML-Seiten statt unverifizierter interner API; Gemini Flash Lite; feste und zusätzliche freie Tags; Google Sheet als manuell prüfbarer Zielort; GitHub Actions als manueller Runner. Risiko: Layoutänderungen; Alternative: offizielle Export-API.
