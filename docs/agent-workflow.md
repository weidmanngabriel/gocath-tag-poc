# Agenten-Workflow
1. Auftrag und entsprechende docs lesen.
2. Grenzen der externen Systeme beachten.
3. Änderungen in kleinen überprüfbaren Schritten durchführen.
4. Unit-Tests starten, externe Integrationen gesondert verifizieren.
5. Docs und Architekturentscheidungen aktuell halten. PR, Checks und Merge nachvollziehbar dokumentieren.
