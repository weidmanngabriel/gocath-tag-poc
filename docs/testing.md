# Tests
Unit-Tests laufen ohne Netzwerk und ohne Zugangsdaten. Prüfen HTML-Linkextraktion, Event-Titel und Tag-Allowlist. Ein erfolgreicher Unit-Test beweist nicht, dass GoCath live dieselbe HTML-Struktur ausliefert oder die Google-Zugangsdaten funktionieren. Integration im manuellen Runner verifizieren; Ergebnisse auf falsche Tags prüfen.
